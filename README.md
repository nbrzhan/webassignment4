## Description

This project was created for Assignment #4: Forms and Validation.

The project demonstrates HTML forms, HTML5 validation, Bootstrap forms, Bootstrap validation, responsive design, and basic JavaScript validation.

## Tasks

### Task 0 - Simple Contact Form

A basic HTML contact form containing:

- Name
- Email
- Message
- Submit button

### Task 1 - HTML5 Validation

The contact form includes HTML5 validation attributes such as:

- required
- type="email"
- minlength
- maxlength

### Task 2 - Bootstrap Form

The contact form is styled using Bootstrap 5 and Bootstrap Grid.

### Task 3 - Bootstrap Validation

Bootstrap validation classes are demonstrated:

- is-valid
- is-invalid
- valid-feedback
- invalid-feedback

### Task 4 - Registration Form

A responsive registration form containing:

- First Name
- Last Name
- Email
- Password
- Confirm Password
- Gender
- Hobbies
- Country
- Register button
- Reset button
